# Brew & Bean Coffee Shop Website

A responsive coffee shop landing page built with HTML5, CSS3, Bootstrap 5.3, Bootstrap Icons, and vanilla JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser. (For best results, use VS Code Live Server.)
3. An internet connection is required for Bootstrap, Bootstrap Icons, Google Fonts, and Unsplash images.

## Features
- Responsive navigation with scroll-tracking (ScrollSpy) and hero section
- Navbar cart shortcut and floating order badge with dynamic bounce animation
- About/story, menu, quote, contact, and footer sections
- Accessible menu category filters with smooth animations
- Balanced 9-item menu grid across Coffee, Cold drinks, and Bakery & bites
- Interactive cart with quantity stepper (`+` / `−`), line remove, and clear cart
- LocalStorage persistence: orders stay intact across page refreshes
- Interactive Checkout Modal with itemized breakdown, tax computation, customer details, and live order confirmation receipt
- Non-intrusive toast notifications on item addition
- Contact form validation and dedicated success confirmation banner
- Mobile-friendly layout with automatic menu collapse on link click

## Notes
The cart and contact form are front-end demonstrations only. Connect a backend and payment provider to receive real orders or enquiries. Replace the sample address, phone number, social links, menu items, and images with your shop's details.
